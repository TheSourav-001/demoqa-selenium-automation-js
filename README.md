# DemoQA Selenium Automation JS

Professional Selenium-JavaScript automation framework for testing DemoQA application.

## Project Structure

```
demoqa-selenium-automation-js/
├── src/
│   ├── pages/          # Page Object Model (POM)
│   │   ├── BasePage.js
│   │   └── LoginPage.js
│   ├── tests/          # Test scripts
│   │   └── login.test.js
│   ├── utils/          # Utility functions
│   │   └── driverSetup.js
│   └── testData/       # Test data
│       └── testData.json
├── package.json
├── .gitignore
└── README.md
```

## Installation

```bash
npm install
```

## Running Tests

```bash
npm test
```

## Technologies

- **Selenium WebDriver** - Web automation
- **Mocha** - Test framework
- **Chai** - Assertion library
- **Mochawesome** - Test reporting
